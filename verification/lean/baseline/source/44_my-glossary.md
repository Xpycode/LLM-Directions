## MVP (Minimum Viable Product)
*Asked: 2026-01-10 during project interview*

The smallest version of your product that delivers core value to users. Not a prototype or demo - it's a real, usable product, just stripped to essentials. Ship this first, then add features based on real feedback.

**Why it matters:** Prevents building features nobody wants. Get something working in users' hands fast.

## Scrolling, Selection, and Modifier Keys
*Asked: 2026-10-12 during Penumbra keyboard acceptance*

Scrolling changes which part of a list is visible. Selection identifies the row an action will operate on. In the tested Penumbra lists, Home/End scroll to the beginning/end without changing selection; Up/Down moves selection. This behavior is context-dependent, not a universal promise for every control.

A modifier key changes another input’s meaning: Shift, Control, Option and Command are examples. Home/End are navigation keys, not modifiers. The right-hand pair in the Magic Keyboard’s six-key navigation block is Page Up/Page Down, distinct from the ordinary arrow keys.

**Why it matters:** A list moving does not mean another clip was selected or loaded.
